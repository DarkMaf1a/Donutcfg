# Donutcfg · Minecraft 26.2

Fabric client target using Java 25, Loom 1.18.2, and unobfuscated Mojang names. No Yarn mapping or manual remapping step is used.

User documentation, downloads, dependencies, and commands are in the [main README](../README.md). See [CONTRIBUTING](../CONTRIBUTING.md) for development instructions.

Build and run local regression checks with `./gradlew build regressionTest` or `gradlew.bat build regressionTest` using JDK 25. The normal mod output is `build/libs/donutcfg-0.5.0+26.2.jar`.
