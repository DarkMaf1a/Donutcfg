# Donutcfg · Minecraft 1.21.11

Fabric client target using Java 21, Loom 1.14.10, and Yarn 1.21.11+build.4.

User documentation, downloads, dependencies, and commands are in the [main README](../README.md). See [CONTRIBUTING](../CONTRIBUTING.md) for development instructions.

Build and run local regression checks with `./gradlew build regressionTest` or `gradlew.bat build regressionTest` using JDK 21. The normal mod output is `build/libs/donutcfg-0.5.0.jar`.
