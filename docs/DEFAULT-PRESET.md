# Built-in `default` preset

The same 14 settings and 43 Quick Buy entries are included in both client builds. Slot numbers here are **1-based**, left to right, nine columns per row. The server's bottom navigation/Edit row is not part of the preset.

Select with `/setcfg default`; apply with `/startcfg all default`, `/startcfg settings default`, or `/startcfg shop default`.
