# Donutcfg 0.5.0 · Minecraft 1.21.11

Save and restore DonutSMP `/settings` and `/shop` Quick Buy with named local profiles.

This mod was vibecoded with AI.

## Install

- **Minecraft Java Edition 1.21.11**, Java **21+**.
- [Fabric Loader](https://fabricmc.net/use/installer/) **0.18.1+**.
- [Fabric API for 1.21.11](https://modrinth.com/mod/fabric-api/versions?g=1.21.11).
- [ViaFabricPlus for 1.21.11](https://modrinth.com/mod/viafabricplus/versions?g=1.21.11).

Put `donutcfg-0.5.0.jar` and matching dependencies into `mods`. Install only one Donutcfg JAR. Select **Minecraft 1.21.5 or below in ViaFabricPlus as the server protocol**, then reconnect. Your actual client must remain **1.21.11** for this asset.

## Included

- Protected `default` profile: 14 settings and the approved 43-item Quick Buy layout.
- `/savecfg`, selection-only `/setcfg`, `/startcfg` and `/loadcfg` with `all|settings|shop` modes.
- `/cfglist`, recoverable `/del cfg`, colored `/cfghelp` and `/cfg help`.
- `/cleanshop` and `/cfg clean`; Cancel button, chat cancellation, and `/stopcfg`.
- Stable/atomic profile saves; recording tools removed.

Quick start: `/startcfg all default`. Save your own setup: `/savecfg mysetup`.

See the [README](https://github.com/DarkMaf1a/Donutcfg#readme) for all commands, dependencies, limitations, and the full preset.
