# Donutcfg 0.5.0 · Minecraft 26.2

The Minecraft 26.2 port of Donutcfg, with the same named-profile controls and approved preset as the 1.21.11 build.

This mod was vibecoded with AI.

## Install

- **Minecraft Java Edition 26.2**, Java **25+**.
- [Fabric Loader](https://fabricmc.net/use/installer/) **0.19.5+**.
- [Fabric API for 26.2](https://modrinth.com/mod/fabric-api/versions?g=26.2).
- [ViaFabricPlus for 26.2](https://modrinth.com/mod/viafabricplus/versions?g=26.2).

Put `donutcfg-0.5.0+26.2.jar` and matching dependencies into `mods`. Install only one Donutcfg JAR. Select **Minecraft 1.21.5 or below in ViaFabricPlus as the server protocol**, then reconnect. Your actual client must remain **26.2** for this asset.

## Included

- All 0.5.0 profile commands, `all|settings|shop` modes, list/delete, Cancel controls, colored help, and Quick Buy cleanup.
- Protected default with 14 settings and 43 items, including separate armor variants and Fortune/Silk Touch pickaxes.
- Java 25 / unobfuscated Mojang API port; Fabric Loader 0.19.5+.
- Import of schema-1 personal profiles saved by the 1.21.11 build. New 26.2 profiles are **not** readable by the older 1.21.11 reader.

Quick start: `/startcfg all default`. Save your own setup: `/savecfg mysetup`.

See the [README](https://github.com/DarkMaf1a/Donutcfg#readme) for complete instructions.
